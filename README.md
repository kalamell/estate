# Estate — ระบบบริหารห้องเช่า

ระบบบริหารอสังหาริมทรัพย์ให้เช่าแบบ **SaaS** ทั้งหอพัก อพาร์ทเมนต์ คอนโด บ้านเช่า และห้องพักรายวัน/Airbnb
Backend เขียนด้วย **Rust (Axum + SQLite)** หน้าเว็บใช้ **React + shadcn/ui** ใช้ได้ทั้ง PC และมือถือ

### SaaS
- 👤 สมัครสมาชิก / เข้าสู่ระบบ — 1 บัญชีสร้างได้หลายองค์กร และ 1 องค์กรมีได้หลายโครงการ
- 🔒 ข้อมูลแต่ละองค์กรแยกขาดจากกัน มีบทบาทเจ้าของ / แอดมิน / พนักงาน
- 📦 แพ็กเกจกำหนดจำนวนโครงการ ห้อง ผู้ใช้ และฟีเจอร์ (OCR, 3D, ห้องรายวัน, ออกบิล)
- 🛡️ หลังบ้าน **Super Admin** สำหรับเจ้าของแพลตฟอร์ม: สร้าง/แก้แพ็กเกจ, กำหนดแพ็กเกจ/สถานะ/วันหมดอายุให้องค์กร, จัดการผู้ใช้, ดู MRR
- ⏳ แพ็กเกจเริ่มต้นแบบฟรีใช้ได้ไม่มีวันหมดอายุ (ถ้าตั้งแพ็กเกจเสียเงินเป็นค่าเริ่มต้นจะได้ทดลองใช้ 14 วัน) บัญชีที่ถูกระงับ/หมดอายุเกินช่วงผ่อนผันจะอ่านได้อย่างเดียว
- 💳 **เก็บค่าแพ็กเกจอัตโนมัติ**: ลูกค้าเลือกแพ็กเกจรายเดือน/รายปี → ใบแจ้งหนี้ + QR พร้อมเพย์ของแพลตฟอร์ม → แนบสลิป → Super Admin ยืนยัน (หรือยืนยันอัตโนมัติเมื่อตรวจสลิปกับธนาคารผ่าน) → ออกใบเสร็จ/ใบกำกับภาษี และต่ออายุทันที
  - ออกใบต่ออายุล่วงหน้าเอง (ตั้งจำนวนวันได้), ช่วงผ่อนผันหลังหมดอายุ, เปลี่ยนแพ็กเกจกลางรอบได้ส่วนลดตามวันที่เหลือ, ลดแพ็กเกจไม่ได้ถ้าใช้งานเกินขีดจำกัด
  - แถบแจ้งเตือนในแอปเมื่อใกล้หมดอายุ / อยู่ในช่วงผ่อนผัน / สลิปไม่ผ่าน

### เอกสารการเงินตามกฎหมาย
- 🧾 ใบแจ้งหนี้ / ใบเสร็จรับเงิน / ใบกำกับภาษี เลขที่เรียงต่อเนื่องตามปี พ.ศ. (INV / RC / DS) ไม่ข้ามเลข
- ข้อมูลผู้ออก (ชื่อนิติบุคคล เลขผู้เสียภาษี สาขา) และผู้จ่าย ถูกบันทึกลงใบเสร็จ ณ วันที่ออก — แก้ย้อนหลังไม่ได้
- VAT เลือกได้ทีละรายการ, หักภาษี ณ ที่จ่าย, จำนวนเงินตัวอักษร (บาทถ้วน), พิมพ์ A4 ต้นฉบับ + สำเนา
- ยกเลิกเอกสารได้พร้อมเหตุผล (เอกสารยังเก็บไว้) — ควรให้นักบัญชีตรวจการตั้งค่า VAT ก่อนใช้งานจริง

### สื่อสารกับผู้เช่า
- 💬 LINE OA: ผู้เช่าดูบิล/ใบเสร็จ/ข้อมูลห้องในแชต และรับบิล ใบเสร็จ การแจ้งเตือนอัตโนมัติ
- 🎨 เปลี่ยนธีมสีได้ 5 แบบ (ตั้งเป็นค่าเริ่มต้นขององค์กร หรือเลือกเองรายผู้ใช้)
- 🧹 งานแม่บ้าน + แจ้งพนักงานทาง LINE · 💰 ราคาตามฤดูกาล/วันหยุด + ส่วนลดพักหลายคืน
- 📅 ปฏิทินการจอง + ซิงก์ Airbnb / Booking.com / Agoda (iCal) + หน้าจองออนไลน์ของหอเอง
- 🔗 พอร์ทัลผู้เช่าผ่านลิงก์ลับ (ส่งทาง LINE): ดูบิล/ใบเสร็จ สแกนจ่าย แจ้งซ่อมพร้อมรูป อ่านประกาศ
- 🛠️ แจ้งซ่อม & ติดต่อ: มอบหมายผู้รับผิดชอบ ติดตามสถานะ บันทึกภายใน
- 📣 ประกาศถึงผู้เช่า และช่องทางให้ลูกค้าติดต่อผู้ให้บริการแพลตฟอร์ม

### การเงินเพิ่มเติม
- ค่าบริการรายเดือนเพิ่มเติมต่อห้อง (อินเทอร์เน็ต ที่จอดรถ) และค่าปรับชำระล่าช้า
- 🚪 ย้ายออก & คืนเงินประกัน: หักค่าเสียหาย/บิลค้างจากเงินประกัน ออกเอกสารคืนเงิน แจ้งกำหนดคืนภายใน 7 วัน
- 📈 รายงาน: รายรับ อัตราเข้าพักย้อนหลัง อายุหนี้ ลูกหนี้ค้างมากสุด ส่งออก CSV (เปิดใน Excel ได้)

### รับเงินและงานหน้าเคาน์เตอร์
- 🧾 **ตรวจสลิปอัตโนมัติ**: ผู้เช่าแนบสลิปในพอร์ทัล หรือ**ส่งรูปสลิปในแชต LINE** → ระบบอ่าน QR บนสลิป (ธนาคาร + เลขอ้างอิง) และ**จับสลิปซ้ำ**ข้ามบิล/ข้ามองค์กร
  - ต่อผู้ให้บริการตรวจสลิป (EasySlip / SlipOK — สมัครเองและมีค่าใช้จ่ายต่อครั้ง) เพื่อยืนยันยอดเงิน ผู้โอน ผู้รับ และ**ยืนยันรับเงิน + ออกใบเสร็จ + ส่ง LINE อัตโนมัติ**
  - ถ้าไม่ต่อผู้ให้บริการ ระบบยืนยันได้ว่าเป็นสลิปที่มี QR ถูกต้องและยังไม่เคยใช้ แต่ยอดเงินต้องให้ทีมงานดูจากรูป
- 📦 **พัสดุ**: บันทึกพัสดุตามห้อง (จับคู่ผู้เช่าให้เอง) → แจ้ง LINE พร้อม**รหัสรับ 4 หลัก** → ส่งมอบพร้อมลายเซ็น/รูป, ตีกลับ, ผู้เช่าพิมพ์ "พัสดุ" ในแชตเพื่อดูของที่รอรับ

### กฎหมายและความเป็นส่วนตัว
- 🛡️ **PDPA**: ประกาศความเป็นส่วนตัวที่แก้ได้ + บันทึกความยินยอม, คำขอใช้สิทธิของเจ้าของข้อมูล (กำหนดตอบ 30 วัน), ส่งออกข้อมูล (JSON), ทำให้ไม่ระบุตัวตน, แจ้งเตือนครบระยะเวลาเก็บข้อมูล
- 📋 **Audit log**: บันทึกการรับเงิน ยกเลิกเอกสาร ลบข้อมูล เปลี่ยนสิทธิ์ ลงนามสัญญา ส่งออกข้อมูล พร้อม IP
- 🛂 **ตม.30 แจ้งที่พักคนต่างด้าว**: เก็บสัญชาติ/พาสปอร์ต/วีซ่า → สร้างรายการให้อัตโนมัติเมื่อผู้เช่าต่างชาติเข้าพัก, นับกำหนด 24 ชม., แจ้งเตือนเจ้าของทาง LINE, ส่งออก CSV ช่วยกรอกในระบบ ตม., เก็บเลขที่รับแจ้งเป็นหลักฐาน, เตือนวีซ่าใกล้หมด
- ✍️ **สัญญาเช่าอิเล็กทรอนิกส์**: แม่แบบพร้อมตัวแปร (ไทย/อังกฤษ) → สร้างจากการจอง → ส่งให้ผู้เช่าลงนามในพอร์ทัล (ลายเซ็น ชื่อ เวลา IP อุปกรณ์ + SHA-256 ของเนื้อหา) → ผู้ให้เช่าลงนาม — แม่แบบเป็นร่างตัวอย่าง ควรให้ทนายตรวจ
- 🔐 ความปลอดภัย: เข้ารหัส token LINE / API key ด้วย AES-256-GCM, จำกัดจำนวนคำขอ, ไฟล์อัปโหลดเปิดได้เฉพาะผู้มีสิทธิ์

### ภาษาอังกฤษสำหรับผู้เช่าต่างชาติ
- 🌐 ผู้เช่าเลือกภาษาไทย/อังกฤษได้ในพอร์ทัล หรือพิมพ์ `English` / `ภาษาไทย` ในแชต — ผู้เช่าต่างชาติและแขกที่จองเป็นภาษาอังกฤษเริ่มที่ภาษาอังกฤษ
- บิล การเตือน ใบเสร็จ พัสดุ ผลตรวจสลิป และสัญญา ส่งทาง LINE ตามภาษาของผู้เช่า, แชตเข้าใจคำสั่งภาษาอังกฤษ (bill, receipt, parcel, repair, info)

### บริหารห้องเช่า

- 🗺️ ดูโครงการทั้งหมดบนแผนที่ ปักหมุดหรือใช้ GPS เพื่อตั้งพิกัด
- 🏢 ผังห้องรายชั้น และ **มุมมอง 3D ทั้งอาคาร** (สีบอกสถานะ คลิกเพื่อเปิดห้อง)
- 🛏️ **มุมมอง 3D ภายในห้อง** ปรับขนาดห้องและจัดวางเฟอร์นิเจอร์ได้
- 📅 สัญญารายเดือน / จองรายวัน กันจองซ้ำ จัดการเงินมัดจำ (รับ / คืน / ริบ)
- 📷 **ถ่ายรูปมิเตอร์ไฟ/น้ำ → อ่านตัวเลขอัตโนมัติ (OCR)** → ตรวจสอบ → บันทึกพร้อมรูปหลักฐาน
- 🧾 ออกบิลรายเดือนอัตโนมัติ (ค่าเช่า + ค่าไฟ + ค่าน้ำ) พร้อม **QR PromptPay** และพิมพ์บิลได้
- 📊 Dashboard: อัตราเข้าพัก รายรับ ยอดค้าง เงินมัดจำ เช็คอินที่ใกล้ถึง

ดูการวิเคราะห์ เว็บ vs แอปเดสก์ท็อป และ roadmap ได้ที่ [docs/RESEARCH.md](docs/RESEARCH.md)

## เริ่มใช้งาน

```bash
cd frontend && npm install && npm run build && cd ..   # สร้างหน้าเว็บ (frontend/dist)
cargo run --release                                     # เปิด http://localhost:3000
```

ระหว่างพัฒนาหน้าเว็บ: รัน `cargo run` ไว้ แล้ว `cd frontend && npm run dev` (Vite proxy `/api` ไปที่ :3000)

ครั้งแรกระบบจะสร้างข้อมูลตัวอย่างให้ — **ปิดด้วย `SEED_DEMO=0` ก่อนใช้งานจริง**

| บัญชีตัวอย่าง | รหัสผ่าน | สิทธิ์ |
|---|---|---|
| `admin@estate.local` | `admin1234` | Super Admin (หลังบ้านแพลตฟอร์ม) |
| `demo@estate.local` | `demo1234` | เจ้าขององค์กร "สุขใจ พร็อพเพอร์ตี้" (แพ็กเกจ Pro) |

ใช้งานจริงให้ตั้ง Super Admin ของคุณเองผ่าน `SUPER_ADMIN_EMAIL` และ `SUPER_ADMIN_PASSWORD`

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `DATABASE_URL` | `sqlite://estate.db?mode=rwc` | ไฟล์ฐานข้อมูล |
| `BIND` | `0.0.0.0:3000` | address ที่รับการเชื่อมต่อ |
| `UPLOAD_DIR` | `uploads` | โฟลเดอร์เก็บรูปมิเตอร์ |
| `STATIC_DIR` | `frontend/dist` | โฟลเดอร์หน้าเว็บที่ build แล้ว |
| `SEED_DEMO` | `1` | สร้างข้อมูลตัวอย่างเมื่อ DB ว่าง |
| `SUPER_ADMIN_EMAIL` / `SUPER_ADMIN_PASSWORD` | – | สร้างหรือเลื่อนสิทธิ์บัญชีนี้เป็น Super Admin ตอนเริ่มระบบ |
| `COOKIE_SECURE` | `0` | ตั้งเป็น `1` เมื่อให้บริการผ่าน HTTPS |
| `PUBLIC_URL` | `http://localhost:3000` | URL สาธารณะ ใช้สร้างลิงก์ในข้อความ LINE และ Webhook URL |
| `TZ` | ระบบ | ตั้ง `Asia/Bangkok` บนเซิร์ฟเวอร์ เพื่อให้วันครบกำหนด/ค่าปรับคิดตามเวลาไทย |

> การใช้กล้องมือถือจดมิเตอร์ต้องเปิดผ่าน HTTPS (หรือ localhost) — ตอนติดตั้งจริงให้วางหลัง reverse proxy เช่น Caddy

## ปฏิทินการจอง และเชื่อม Airbnb / Booking.com / Agoda

- **ปฏิทินรวม** (เมนู ปฏิทินการจอง): ทุกห้องในตารางเดียว สีตามช่องทาง เตือนการจองซ้อน ลากเลือกช่วงวันเพื่อสร้างการจอง
- **ซิงก์ผ่าน iCal** (ห้องพัก → เลือกห้อง → แท็บ ปฏิทิน & ช่องทางขาย):
  1. *Import*: คัดลอกลิงก์ส่งออกปฏิทิน (Export calendar) จาก Airbnb / Booking.com Extranet / Agoda YCS มาวาง — ระบบดึงทุก 30 นาที
  2. *Export*: คัดลอกลิงก์ของระบบไปวางในช่อง "นำเข้าปฏิทิน" ของแต่ละช่องทาง (ใช้ลิงก์ `?exclude=` ของช่องทางนั้นเพื่อไม่ส่งการจองของมันกลับไปหาตัวเอง)
  3. วันที่ถูกจองในช่องทางหนึ่งจะถูกปิดในระบบและช่องทางอื่นอัตโนมัติ — ระบบไม่ให้สร้างการจองทับ
- iCal ส่งเฉพาะช่วงวันที่ไม่ว่าง (ไม่มีชื่อแขก/ราคา) และอัปเดตเป็นรอบ — การเชื่อม API เต็มรูปแบบของ Airbnb/Booking.com ต้องสมัครเป็นพาร์ทเนอร์ของแต่ละแพลตฟอร์ม
- ระบบไม่ดึงลิงก์ที่ชี้ไปยังเครือข่ายภายใน (กัน SSRF) — ใช้ `ALLOW_PRIVATE_FEED_URLS=1` เฉพาะตอนทดสอบ

## หน้าจองออนไลน์ (จองตรง ไม่เสียค่าคอมมิชชัน)

เปิดได้ในหน้าแก้ไขโครงการ → **หน้าจองออนไลน์** (ตั้งชื่อลิงก์ เวลาเช็คอิน/เอาท์ คืนขั้นต่ำ % มัดจำ) แล้วแชร์ลิงก์ `/stay/<ชื่อลิงก์>`
แขกเลือกวันที่ว่างและห้อง → ส่งคำขอ (กันห้อง 24 ชม. / 72 ชม. เมื่อแนบสลิป) → สแกน PromptPay จ่ายมัดจำ → ทีมงานอนุมัติในแท็บ **คำขอจองออนไลน์** ระบบสร้างผู้เช่าและการจองให้อัตโนมัติ

## งานแม่บ้าน

- เมนู **งานแม่บ้าน** (ใช้บนมือถือได้): เช็คเอาท์/เช็คอินวันนี้ สถานะความสะอาดของทุกห้อง และกระดานงาน
- แขกรายวันเช็คเอาท์ → สร้างงานทำความสะอาดอัตโนมัติ (ผู้เช่ารายเดือนย้ายออก → ทำความสะอาดใหญ่) ห้องเป็น "รอทำความสะอาด" จนกว่างานเสร็จ
- เช็กลิสต์ตามประเภทงาน แนบรูป มอบหมายพนักงาน
- พนักงานกด **ตั้งค่า → สมาชิก → เชื่อม LINE ของฉัน** เพื่อรับแจ้งงานใหม่ทาง LINE OA และพิมพ์ `งาน` เพื่อดูงานวันนี้

## ราคาตามฤดูกาล

โครงการ → **ราคาตามฤดูกาล**: ตั้งกฎตามช่วงวันที่ (high season, สงกรานต์, ปีใหม่) หรือวันในสัปดาห์ (ศ–ส) แบบตั้งราคา/ปรับ %/ปรับบาท พร้อมลำดับความสำคัญ
และส่วนลดพักหลายคืนเป็นขั้น — ราคานี้ใช้ทั้งหน้าจองออนไลน์และตอนทีมงานสร้างการจองรายวัน

## เชื่อมต่อ LINE Official Account

ผู้เช่าแอดเพื่อน LINE@ ของหอ เชื่อมบัญชีครั้งเดียว แล้วรับบิล ใบเสร็จ และการแจ้งเตือนทาง LINE อัตโนมัติ
พิมพ์หรือกดเมนู **บิล / ใบเสร็จ / พัสดุ / ข้อมูลของฉัน / แจ้งซ่อม** เพื่อดูข้อมูลของตัวเองได้ทุกเมื่อ, **ส่งรูปสลิป**เพื่อแจ้งชำระ, พิมพ์ `English` เพื่อเปลี่ยนเป็นภาษาอังกฤษ

1. ตั้ง `PUBLIC_URL` เป็นโดเมน HTTPS ของระบบ (เช่น `https://estate.example.com`) — LINE เรียก webhook ได้เฉพาะ HTTPS ที่เข้าถึงจากอินเทอร์เน็ต
2. สร้าง LINE Official Account ที่ [LINE Official Account Manager](https://manager.line.biz) และเปิดใช้ Messaging API
3. ที่ [LINE Developers Console](https://developers.line.biz/console/) คัดลอก **Channel secret** และออก **Channel access token (long-lived)**
4. ในระบบ: ตั้งค่าองค์กร → **LINE OA** ใส่ค่าทั้งหมด กดบันทึก แล้วคัดลอก **Webhook URL** ไปวางใน Developers Console → Verify → เปิด *Use webhook*
5. ใน OA Manager ปิด *ข้อความตอบกลับอัตโนมัติ* และ (แนะนำ) สร้าง Rich menu ที่ส่งข้อความ `บิล`, `ใบเสร็จ`, `ข้อมูลของฉัน`, `แจ้งซ่อม`
6. ผู้เช่าเชื่อมบัญชีได้ 2 ทาง: กดปุ่ม **เชื่อมบัญชี LINE** ในพอร์ทัลผู้เช่า หรือสแกน QR จากหน้า **ผู้เช่า → เชื่อม LINE**

การส่งอัตโนมัติ (เปิด/ปิดได้): บิลใหม่, ใบเสร็จหลังรับชำระ, คำตอบเรื่องแจ้งซ่อม, พัสดุมาถึง, เตือนก่อนครบกำหนด 1 วัน และเมื่อค้างชำระวันที่ 1, 3, 7 (ส่งช่วง 09:00–20:00)
ทีมงานที่เชื่อม LINE (ตั้งค่า → สมาชิก) ได้รับงานแม่บ้าน และเจ้าของ/แอดมินได้รับแจ้งเตือน ตม.30
