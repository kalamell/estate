# คลิปแนะนำระบบ Estate

คลิปนี้บันทึกจากหน้าจอของระบบจริง ได้แก่ แอปของทีมงาน พอร์ทัลผู้เช่า และหน้าพิมพ์ใบเสร็จ ข้อมูลในคลิปเป็นข้อมูลตัวอย่าง ชื่อผู้เช่าเป็นชื่อสมมติ คลิปไม่มีเสียงพูดและไม่มีเพลง ใส่เสียงพากย์เองได้ตามขั้นตอนด้านล่าง

## อัปโหลดขึ้น YouTube แล้วแสดงบนหน้าแนะนำระบบ

1. เข้า [studio.youtube.com](https://studio.youtube.com) กด "สร้าง" แล้วเลือก "อัปโหลดวิดีโอ" เลือกไฟล์ `estate-promo-1080p.mp4`
2. ใส่ชื่อคลิป เช่น "Estate ระบบหลังบ้านสำหรับหอพักและห้องเช่า" แล้วใช้ `cover-1280x720.png` เป็นภาพขนาดย่อ
3. ในขั้น "ระดับการเข้าถึง" เลือก "ไม่เป็นสาธารณะ" (Unlisted) ได้ คนที่มีลิงก์และคนที่เปิดหน้าแนะนำระบบยังดูได้ แต่คลิปจะไม่ขึ้นในผลค้นหา
4. เมื่ออัปโหลดเสร็จ กด "คัดลอกลิงก์" จะได้ลิงก์แบบ `https://youtu.be/xxxxxxxxxxx`
5. เข้าระบบ Estate ด้วยบัญชี Super Admin ไปที่เมนู "ผู้สนใจ" เลื่อนลงไปที่การ์ด "หน้าแนะนำระบบ"
6. วางลิงก์ในช่อง "ลิงก์คลิป YouTube หรือ Vimeo" แล้วกด "บันทึก" การ์ดจะแสดงตัวอย่างทันที หน้าแรกจะแสดงคลิปต่อจากส่วนหัว
7. ถ้าต้องการเอาคลิปออก กด "นำคลิปออก" ส่วนคลิปบนหน้าแรกจะหายไป

ระบบรับลิงก์ YouTube (`youtube.com/watch?v=…`, `youtu.be/…`, Shorts) และ Vimeo หน้าแรกจะแสดงรูปปกกับปุ่มเล่นก่อน และจะโหลดตัวเล่นของ YouTube ก็ต่อเมื่อผู้ชมกดเล่น

ถ้าอยากให้ผู้ชมเปิดคำบรรยายเองแทนคำบรรยายในภาพ ให้อัปโหลด `estate-promo-1080p-nocaptions.mp4` แล้วไปที่ "คำบรรยาย" ใน YouTube Studio เลือก "อัปโหลดไฟล์" แบบ "มีการกำหนดเวลา" แล้วเลือก `estate-promo-captions.srt` อย่าใช้ไฟล์ `.srt` กับคลิปที่มีคำบรรยายในภาพอยู่แล้ว เพราะผู้ชมจะเห็นข้อความซ้อนกันสองชุด

## ใส่เสียงพากย์

วิธีที่ง่ายที่สุดคือเปิดคลิปในโปรแกรมตัดต่อที่ใช้อยู่ (เช่น CapCut, iMovie หรือ YouTube Studio) วางไฟล์เสียงลงบนเส้นเวลา แล้วเลื่อนแต่ละช่วงให้ตรงเวลาในตารางด้านบน

ถ้ามีไฟล์เสียงที่อัดยาวต่อเนื่องเท่าคลิปแล้ว รวมไฟล์ด้วย ffmpeg ได้โดยไม่เข้ารหัสภาพใหม่

```
ffmpeg -i estate-promo-1080p.mp4 -i voice.m4a -map 0:v -map 1:a -c:v copy -c:a aac -b:a 160k -shortest estate-promo-1080p-voice.mp4
```

ถ้าจะใส่เพลงประกอบภายหลัง ใช้เพลงที่มีสิทธิ์ใช้งาน เช่น จากคลังเสียงของ YouTube Studio เพื่อไม่ให้คลิปโดนแจ้งลิขสิทธิ์
